# Cloudflare Workers AI для StudyFlow

Адаптер подготовлен и проверяется с подменённым HTTP. Реальная доступность модели,
качество русских объяснений и чтения фото требуют проверки после подключения аккаунта.
На существующем сайте провайдер пока OpenAI; автоматического переключения нет.

## Что делает владелец

1. Зарегистрируйся или войди в [Cloudflare](https://dash.cloudflare.com/).
   Подтверди свою почту и самостоятельно ознакомься с условиями сервиса.
2. Открой **Workers AI → Use REST API → Create a Workers AI API Token**.
   Используй предложенный шаблон для нужного аккаунта; скопируй API Token и Account ID.
   Не передавай токен в чат, GitHub, скриншоты или клиентский JavaScript.
3. Убедись, что аккаунт использует **Workers Free**. Не включай Workers Paid,
   предоплаченные AI Gateway credits или платёжный метод ради этого подключения.
   Если интерфейс требует оплату, остановись и сообщи об этом без секретов.
4. В [Render → StudyFlow → Environment](https://dashboard.render.com/web/srv-db3uichsrm7s73a9aseg/env)
   добавь значения из таблицы. Существующие настройки базы и Neon Auth оставь на месте.
   Сохрани изменения с развёртыванием сервиса.

| Переменная | Значение |
| --- | --- |
| `STUDYFLOW_AI_PROVIDER` | `cloudflare` |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из Cloudflare, 32 шестнадцатеричных символа |
| `CLOUDFLARE_API_TOKEN` | Твой API Token, только в серверном Environment |
| `CLOUDFLARE_MODEL` | `@cf/google/gemma-4-26b-a4b-it` |
| `STUDYFLOW_AI_USER_DAILY_LIMIT` | `20` |
| `STUDYFLOW_AI_GLOBAL_DAILY_LIMIT` | `100` |

Приложению не нужен отдельный Worker, домен или AI Gateway.
После сохранения достаточно сообщить «добавил настройки» без самих значений.
Ассистент сможет проверить выпуск и настоящий учебный цикл на синтетическом задании.

## Что уже делает приложение

- Проверяет Account ID, наличие токена и модель из разрешённого списка до AI-запроса.
- Отправляет данные только явно выбранному провайдеру; нет автоматического перехода
  на OpenAI, другую модель или платный сервис после ошибки.
- Использует Chat Completions, JSON mode и прежние локальные Pydantic-схемы.
  Неполные или неверные ответы не превращаются в сохранённые тесты и задания.
- Перед отправкой фото показывает название получателя. Старое окно с другим
  получателем получает просьбу обновить страницу вместо передачи изображения.
- Не сохраняет фото на сервере; не пишет ключ, фото, учебный текст и исходную ошибку
  провайдера в диагностику. В запросе отключены stream, store и thinking.
- Ограничивает запросы в базе и показывает отдельную ошибку при исчерпании
  бесплатной квоты; нет автоматических повторов, покупок или смены тарифа.

Проверка `/api/config` показывает `ai_provider` и `ai_ready` без секретов.
`ai_ready=true` означает корректную форму настроек, а не проверку токена, тарифа
или качества модели. Приложение не определяет платёжный тариф аккаунта через API:
для отсутствия списаний важно оставить именно Workers Free.

## После включения — проверка ассистентом

1. Дождаться Render Live, проверить health и публичную конфигурацию.
2. На отдельном тестовом аккаунте пройти настоящее фото → черновик → подтверждение
   → план → Tutor → мини-тест → оценка → карта знаний.
3. Проверить отсутствие секретов в публичных ответах и сохранение результата после redeploy.
4. При недоступности модели сохранить обычные функции и сообщить точную причину;
   не подключать платную замену без новой задачи пользователя.

Ручная проверка настоящего почтового OTP и входа с телефона остаётся владельцу.

## Лимиты и источники

На 2 ноября 2026 документация указывает 10 000 Neurons в день бесплатно,
сброс в 00:00 UTC. На Workers Free превышение останавливает запросы;
на Workers Paid превышение может тарифицироваться. Neurons не равны числу запросов,
поэтому локальные лимиты 20/100 не гарантируют, что бесплатной квоты хватит.

- [Официальный запуск REST API и шаблон токена](https://developers.cloudflare.com/workers-ai/get-started/rest-api/).
- [Тарифы, бесплатная квота и модели с обязательной оплатой](https://developers.cloudflare.com/workers-ai/platform/pricing/).
- [Gemma 4 26B A4B: параметры и обработка изображений](https://developers.cloudflare.com/workers-ai/models/gemma-4-26b-a4b-it/).
- [Совместимость Chat Completions](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/).
- [Коды ошибок](https://developers.cloudflare.com/workers-ai/platform/errors/).

Модель выбрана по документации и не входит в опубликованный список моделей
с обязательным платёжным методом. Это не заменяет реальную проверку аккаунта.
