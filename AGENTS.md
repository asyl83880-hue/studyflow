# StudyFlow

Персональный учебный навигатор. Пользовательские тексты — на русском.
Сохраняй React/Vite и FastAPI; личные данные размещённого приложения хранятся в Neon PostgreSQL.

## Карта проекта

- `PROJECT_STATE.md` — актуальное состояние, адреса, подтверждённые проверки и незавершённые задачи. Прочитай перед продолжением работы.
- `README.md` — запуск и конфигурация.
- `src/App.jsx` — общий список заданий, изменения статуса и панели действий.
- `src/components/` — страницы и формы; `src/utils/dates.js` — календарь и местные даты.
- `src/api.js`, `src/auth.js`, `src/components/AuthGate.jsx` — запросы, сессия и формы аккаунта.
- `backend/app/main.py`, `crud.py`, `schemas.py` — задания и их валидация.
- `backend/app/planner.py`, `planner_routes.py` — планирование без внешнего AI.
- `backend/app/auth.py`, `database.py`, `models.py` — проверка владельца и хранение.
- `tests/` — клиентские регрессии, включая формы React в изолированном DOM.
- `backend/tests/` — серверные и интеграционные проверки; `.github/workflows/ci.yml` — PostgreSQL и Docker.

## Правила изменений

- Выполняй текущую задачу без добавления крупных несвязанных функций.
- Сохраняй разделение данных по `owner_id`; чужие идентификаторы не должны раскрывать записи.
- Учитывай часовой пояс браузера при отображении дедлайнов; API передаёт явное смещение UTC.
- Ошибка сети должна оставлять введённые данные и возможность повторить действие.
- Ключи, JWT, пароли, коды из писем и строки подключения не сохраняй в Git и не выводи в логи.
- Не подключай платные ресурсы или другого AI-провайдера без соответствующей задачи пользователя.
- Не называй проверку с подменённым AI успешным прохождением настоящего AI-цикла.

## Проверка и завершение

- Клиент: `npm test`, затем `VITE_API_URL=/api npm run build`.
- Сервер: `python -m pytest backend/tests -q` в окружении с `backend/requirements-dev.txt`.
- Перед завершением публикации дождись успешного CI и статуса Render Live для нужного коммита.
- Запиши изменения, границы проверок и оставшиеся задачи в `PROJECT_STATE.md`.
