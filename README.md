# StudyFlow

Персональный AI-навигатор школьника: задания, календарь, Smart Planner, Tutor,
мини-тесты и карта знаний.

Существующий сайт: https://studyflow-27y8.onrender.com

## Версия с личными аккаунтами

Версия с личными аккаунтами опубликована на Render и использует постоянный Neon PostgreSQL.
Регистрация, разделение данных и сохранение задания после повторного развёртывания проверены.

**Статус AI:** прежнее подключение OpenAI заблокировано балансом API.
Подготовлен отдельный адаптер Cloudflare Workers AI для бесплатной квоты:
фото, Tutor и мини-тесты. Он ещё не включён: нужны аккаунт и серверный токен владельца.
Порядок подключения без оплаты: [CLOUDFLARE_SETUP.md](CLOUDFLARE_SETUP.md).

- Регистрация, вход, выход, подтверждение почты и восстановление пароля — Neon Auth.
- FastAPI проверяет короткий JWT по подписи Ed25519, issuer и сроку действия.
- Задания, тесты, результаты, карта знаний и настройки браузера разделены по пользователям.
- Хранилище — отдельный PostgreSQL в Neon; перезапуск Render не удаляет такую базу.
- Ключ выбранного AI-провайдера остаётся на сервере; AI имеет дневные лимиты на пользователя и на весь сервис.

## Задания и планирование

- «Новое задание» открывает ручную форму: для создания задания и плана внешний AI не требуется.
- Кнопка «Вернуть в работу» отменяет отметку выполнения. Задание снова учитывается в плане и календаре.
- Перед удалением показаны предмет и тема. При ошибке можно повторить удаление из той же панели.
- Изменение периода плана сохраняет занятость будущих дней, включая дни за пределами выбранного периода.

## Стек

React 19 / Vite / Node 24; FastAPI / Python 3.12 / SQLAlchemy;
Neon PostgreSQL через psycopg; Managed Neon Auth; OpenAI Responses API или Cloudflare Chat Completions.
SQLite доступен для изолированных тестов и локальной разработки.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r backend/requirements-dev.txt
npm ci
```

Скопируй `backend/.env.example` в `backend/.env` и заполни настройки своей ветки Neon.
Пароль базы, OPENAI_API_KEY и CLOUDFLARE_API_TOKEN нельзя загружать в GitHub.

В двух терминалах из корня проекта:

```bash
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

```bash
npm run dev
```

Открой http://127.0.0.1:5173. В Neon Auth разреши origin этого интерфейса.
Сервер берёт публичный Auth URL из своей конфигурации, отдельный VITE-ключ не нужен.

## Проверки

```bash
python -m pytest backend/tests -q
npm test
npm run build
```

CI дополнительно выполняет те же API-проверки на PostgreSQL 17 и собирает Docker.
В автоматическом учебном цикле заменён только внешний HTTP выбранного AI-провайдера.
Реальный Neon Auth и доставка почтовых кодов проверены на тестовом алиасе.
Принятие настоящего OTP/смена пароля ещё требуют ручной проверки: Gmail скрывает коды
от автоматического доступа. Настоящий Cloudflare ещё не проверен; OpenAI заблокирован балансом API.
Проверки последних изменений: https://github.com/asyl83880-hue/studyflow/actions.
