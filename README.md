# StudyFlow — постоянное размещение

React + FastAPI + SQLite. Этот пакет содержит исходники для GitHub и Render.
Инструкция: HOSTING_GUIDE.md. Конфигурация: render.yaml + Dockerfile.
Размещение создаёт платный сервер с постоянным диском. Цена показана в Render
перед созданием. Это общее демо с кодом доступа; личных кабинетов пока нет.

Полный проект, локальный запуск и автопроверки находятся в StudyFlow.zip.
Фактические проверки и ограничения: HOSTING_CHECKS.md и PROJECT_STATE.md.
