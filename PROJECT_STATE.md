- Регистрация/вход/выход/Email OTP через официальный SDK Managed Neon Auth.
- API проверяет EdDSA JWT по фиксированному JWKS, issuer origin, exp/iat/sub.

- Вместо общего кода — личный вход; навигация на компьютере и телефоне содержит выход.
- Новый PostgreSQL URL имеет приоритет над старым SQLite URL.
- Публичный сервер может требовать PostgreSQL, чтобы случайно не запустить аккаунты с временными данными.
- AI-лимиты в базе: по умолчанию 20 запросов/сутки на пользователя и 100 на сервис.

приложения; API принимает его заголовком Authorization: Bearer.
Длительная сессия управляется провайдером Auth. После выхода уже выданный JWT
имеет ограниченный остаточный срок действия, до 15 минут.
