## Данные

Личные таблицы: assignments, practice_tests, practice_results, practice_answers,
task_request_keys, usage_counters. Пароли/сессии — Managed Neon Auth.
Старые общие таблицы демо сохраняются отдельно; новым аккаунтам не выдаются.
Историческая ссылка теста на задание не удаляет результат при удалении задания.
Фотографии обрабатываются в памяти, на сервере не сохраняются.

## Runtime

- STUDYFLOW_POSTGRES_URL: секретный pooled PostgreSQL URL с TLS.
- STUDYFLOW_REQUIRE_POSTGRES=true на Render.
- NEON_AUTH_BASE_URL и NEON_AUTH_JWKS_URL одной ветки Neon.
- OPENAI_API_KEY / OPENAI_MODEL — существующие серверные настройки.
- STUDYFLOW_AI_USER_DAILY_LIMIT=20, STUDYFLOW_AI_GLOBAL_DAILY_LIMIT=100.

Auth URL приходит в браузер через публичный /api/config. JWT хранится только в памяти
приложения; API принимает его заголовком Authorization: Bearer.
Длительная сессия управляется провайдером Auth. После выхода уже выданный JWT
имеет ограниченный остаточный срок действия, до 15 минут.
